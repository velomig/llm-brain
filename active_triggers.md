# Active Triggers

Generic template. Keep personal goals and trigger values in local, ignored calibration files.

## Financial
- **Liquidity Threshold**: [Amount] in cash or [Percentage] of portfolio.
- **Asset Reallocation**: [Ticker] reaches [Price] -> Prepare review package.

## Career & Income
- **New Income Stream**: [Event/Date] -> Review budget/contribution rate.

## Projects
- **Research Window**: [Date/Timeframe] -> Start project research.
- **Ready Signal**: [Manual Trigger] -> Review next steps.
