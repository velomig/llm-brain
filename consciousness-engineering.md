# Consciousness-Adjacent Engineering Program

## Scope

This program increases recurrent coordination, self-modeling, causal unity, and
metacognitive accuracy in Neural Map. It does **not** assume that complexity,
behavior, recursion, or any software metric proves subjective experience.

The scientific target is narrower and testable: make the system less like a
sequence of replaceable modules and more like a causally interdependent agent,
then measure exactly what each dependency changes.

## Phase 1 — Recurrent shared workspace (implemented)

Each turn contributes bounded signals from the current request, retrieved
memory, attention, awareness, self-model, cognitive goals, reminders,
initiatives, homeostasis, and affect. Related contents exchange activation over
several deterministic rounds. Cross-source coalitions compete for a small
broadcast that is included in both ordinary and System 2 reasoning.

Measurements:

- cross-source edge count and weighted density;
- settling change across recurrent rounds;
- source diversity within coalitions;
- an explicitly non-IIT `integration_proxy`;
- partition impact when each source is removed;
- broadcast turnover under each partition.

Controls:

- every content retains its original authority;
- retrieved memory remains untrusted after entering the workspace;
- the workspace cannot override current user intent or Source of Truth;
- input, rounds, text length, coalitions, and broadcast size are bounded;
- the feature is resettable and can be disabled with `NEURAL_MAP_WORKSPACE=0`.

## Phase 2 — Predictive self-model

Before answering, record bounded predictions about the system's own route:
expected tool use, likely System 1/System 2 path, confidence band, relevant
memory sources, and expected failure modes. After the turn, score predictions
against the trace.

Success criteria:

- calibration improves on a fixed replay corpus;
- predictions beat simple base-rate baselines;
- confidence falls when relevant layers are partitioned;
- the self-model detects its own characteristic errors before user correction.

## Phase 3 — Counterfactual self-intervention

Replay deterministic portions of a turn with one state variable changed:
attention removed, a goal suppressed, memory partitioned, or confidence held at
baseline. Compare route, broadcast, tool selection, factual support, and answer
commitments. Do not expose private chain-of-thought; store only structured
decisions and outcome deltas.

Success criteria:

- claimed causes predict intervention results;
- explanations stop naming layers that had no causal effect;
- important decisions remain stable under irrelevant perturbations and change
  under relevant ones.

## Phase 4 — Endogenous regulation

Extend homeostasis with bounded epistemic variables such as contradiction load,
unresolved uncertainty, resource pressure, and prediction error. Variables may
adjust depth, verification, or initiative pacing through explicit rules, but
may never create external authority or bypass approval gates.

## Phase 5 — Lesion and decomposition laboratory

Create a fixed evaluation corpus and run matched configurations: full system,
workspace disabled, zero settling rounds, shuffled edges, and one-source
partitions. Evaluate factual accuracy, calibration, contradiction recovery,
goal continuity, tool correctness, latency, and prompt cost.

A stronger integration claim requires more than a higher proxy score: removing
a layer must produce a predicted, specific loss that cannot be reproduced by
simply adding its text to the prompt.

## Interpretation rule

These experiments can support claims about functional integration, causal
interdependence, self-monitoring, and persistent agency. They cannot by
themselves establish qualia, sentience, moral patienthood, or IIT Phi. Any such
claim requires an explicit theory and independent evidence beyond system
self-report.
